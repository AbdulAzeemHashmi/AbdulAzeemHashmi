## 🚀 Featured Projects

### 📊 Instagram Usage & Lifestyle Database Analysis
Designed and implemented a relational database to analyze the correlation between Instagram usage and user health/lifestyle. Included ERD design, Python-based data insertion (1,200 records), and complex SQL analytical queries.

**Tech:** MySQL · SQL · Python (pandas, mysql-connector) · Jupyter  
**🔗 [View Project](https://github.com/AbdulAzeemHashmi/Instagram-Lifestyle-DB-Analysis)**

### 🎬 Movie Data Manager (C++ No-STL)
A comprehensive console-based system to manage and analyze the IMDb 5000 dataset. Built entirely from scratch without the C++ STL, featuring manual implementations of AVL Trees for O(log n) search, Hash Tables for indexing, and Graphs (BFS/DFS) for a movie recommendation engine.

**Tech:** C++ · Custom Data Structures (AVL, Hash Tables, Graphs) · Algorithms  
**🔗 [View Project](https://github.com/AbdulAzeemHashmi/MOVIE-DATA-MANAGER)**

### 🏎️ RC-CAR
Repository for an RC car project includes embedded/C++ code, data logging, and Python tooling for analysis and visualization of experiment logs.

**Tech:** C++ · Python · Data Logging  
**🔗 [View Project](https://github.com/AbdulAzeemHashmi/RC-CAR)**
